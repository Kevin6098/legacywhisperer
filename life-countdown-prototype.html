Legacy Whisperer

生命倒计时 App 原型设计 - 可直接用于开发实现

📋 产品规划与功能设计

核心功能

  • 生命倒计时：显示从出生日期开始的生命时长（年、月、日、时、分、秒）
  • 最后留言：支持文字、语音、视频三种留言方式，3天未活动时自动发送给指定收件人
  • 紧急联系人：设置紧急联系人，2天未活动自动通知
  • 活动追踪：自动记录用户活动，监控应用使用情况
  • 提醒系统：1天、2天、3天未活动时自动触发不同级别的提醒

页面架构

  • 首页：生命倒计时显示、日常激励语录、统计信息（总时长、上次活动时间）
  • 设置页：基本信息设置、紧急联系人管理、最后留言设置、提醒开关
  • 添加/编辑页：添加或编辑紧急联系人、最后留言收件人

视觉设计要点

  • 色彩方案：使用温和的蓝灰色系（#7A8C99, #6B7C85），营造平静、安心的氛围
  • 图标系统：使用 FontAwesome 图标库，保持一致的视觉风格
  • 卡片设计：采用圆角卡片布局，使用半透明背景增强层次感
  • 状态指示：清晰的状态显示，让用户一目了然

💻 开发实现建议

技术栈推荐

  • iOS：Swift + SwiftUI，本地数据存储使用 UserDefaults 或 Core Data
  • Android：Kotlin + Jetpack Compose，本地数据存储使用 SharedPreferences 或 Room Database
  • 跨平台：React Native 或 Flutter（可选）

核心功能实现

  • 倒计时计算：使用出生日期计算总时长，每秒更新显示（年、月、日、时、分、秒）
  • 活动追踪：监听应用打开、页面焦点变化，记录最后活动时间
  • 提醒系统：使用本地通知（Local Notifications）实现1天、2天、3天未活动的提醒
  • 自动通知：2天未活动时通过短信/邮件API自动通知紧急联系人
  • 最后留言发送：3天未活动时通过邮件API自动发送最后留言

注意事项

  • 确保所有交互元素符合最小触摸区域（44x44px）
  • 适配不同屏幕尺寸和分辨率
  • 考虑深色模式支持（可选）
  • 实现数据备份与恢复功能
  • 保护用户隐私，敏感信息加密存储
  • 短信/邮件发送需要后端服务支持（可使用 Twilio、SendGrid 等服务）
